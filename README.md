# ErdenVaux

An original fictional luxury bags application created in November 2026. The independent Next.js portfolio demo is being built around eight imagined silhouettes, accurate variant imagery, a persistent bag/wishlist and a complete local checkout simulation. No real purchase or payment is made.

Node 22.23.1 and npm 10.9.8. Run `npm ci` and `npm run dev` inside this repository. Static GitHub Pages hosting is planned under `/erdenvaux-bags-next/`.

The delivery plan is in [docs/IMPLEMENTATION_PLAN.md](docs/IMPLEMENTATION_PLAN.md). Verification evidence and the public demo will be recorded after completion.
